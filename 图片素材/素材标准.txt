========================================================
  图片素材 · 标准
========================================================
这个文件夹里的图，文件名全是**通用名字**（主角-*、场景-*、配角-* …），
不带任何具体角色或地名。

所以：
  · 想把主角换成别的角色 → 换掉「主角-*」这三张就行
  · 想把地图换成提瓦特/别的世界 → 换掉「场景-*」这些图，
    再去 src/data/destinations.js 改地区列表
  · 想换个家 → 换掉「家」这一张

**换素材不需要改代码**（除了换地图要改地区列表）。
后缀随便：.png / .jpg / .jpeg / .webp 都会自动认。


========================================================
通用要求
========================================================
· 人物立绘、玩具：PNG + 透明背景（不要白底）
· 场景、家：JPG 或 PNG 都行，不需要透明
· 画面里不要写任何文字
· 同一个人物的多张图，画风和身高比例必须一致
· **脚底/底边要贴着图片的下边缘**（代码按底边对齐地面）
· 图片四周多余的空白会被自动裁掉，所以留白多少都不影响


========================================================
一、主角立绘（3 张）
========================================================
文件名：主角-待机 / 主角-开心 / 主角-疲惫
格式：PNG，透明背景
尺寸：1024 × 2048（竖版，宽:高 = 1:2）
要点：三张的身高、画风、配色必须一致，最好一次画完

  主角-待机    站着，双手自然放下，表情平静
               用在：发呆、看书、浇水、望着路口

  主角-开心    微笑，手稍微抬起来一点
               用在：玩耍、吃饭、做饭、伸懒腰

  主角-疲惫    眼睛半闭，有点没精神
               用在：走累了、掉进河里之后、睡觉

  【可选】主角-坐着
               1024×2048 透明底，**屁股贴着图片下边缘**
               补了这一张，玩吊床时就能真的躺在上面。


========================================================
二、场景背景（每个地区一张，目前 17 张）
========================================================
文件名：场景-<地区名>，例如 场景-北京
格式：JPG 或 PNG，不需要透明
尺寸：2048 × 1152 起（横版 16:9）
要点：· **画面里不要出现人物**（主角和配角是之后贴上去的）
      · 下方四分之一留出比较干净的地面
      · 中间偏下别放太抢眼的元素（会被邮戳和手写短句压住）
      · **昼夜和天气不用另画** —— 4 时段 × 3 天气 = 96 种观感，
        全部由代码叠色生成，所以每个地方只要一张白天晴天的底图

当前地区列表（要改地图就改 src/data/destinations.js）：
  北京 / 哈尔滨 / 呼伦贝尔 / 吐鲁番 / 敦煌 / 林芝 / 成都 / 西安 /
  张家界 / 苏州 / 杭州 / 厦门 / 桂林 / 大理 / 三亚 / 广州 / 漠河


========================================================
三、配角立绘（目前 8 张）
========================================================
文件名：配角-<角色名>，例如 配角-派蒙
格式：PNG，透明背景
尺寸：1024 × 2048（和主角完全一样）
要点：**身高比例和主角对齐**，脚底同样贴着图片下边缘；
      建议和主角同一批次画，否则拼在一张明信片上会看出来

当前配角列表（要改就改 src/data/companions.js）：
  派蒙 / 柯莱 / 提纳里 / 赛诺 / 妮露 / 迪希雅 / 可莉 / 七七


========================================================
四、家的全景（1 张）
========================================================
文件名：家
格式：PNG 或 JPG，不需要透明
尺寸：2048 × 1152 起（横版 16:9）

推荐构图（横向分三块）：
  左三分之一：半截面的屋子内部。**要能看见屋里** ——
              书架、床、桌子、灶台、窗、墙上搁板。
              切开一半，这样不用切场景也能看见她在屋里做什么。
  中三分之一：院子。篱笆 + 两块田（一块旱田、一块水田）
  右三分之一：花园。树、花丛、水池

**换这张图要注意两件事**：
  1. 她站的位置和玩具摆的位置，是按这张图量出来的固定坐标，
     换图后要去 src/data/home.js 改 homeSpots 和 toySlots
  2. 田地和玩具的外观是画在图里的，代码不会再往上画
     所以换图 = 田地长什么样就固定了


========================================================
五、玩具（目前 9 件）
========================================================
文件名：玩具-<名字>
格式：PNG，透明背景
尺寸：512 × 512
要点：底边对齐地面（图的下边就是玩具落地的那条线）
      视角尽量和「家」那张图一致，否则会像贴上去的

**最多同时摆 5 件**，全部摆在右边的院子里。
游戏里的玩具面板会显示「摆放位置 3 / 5」，满了会提示先收回一件。

尺寸是按「相对主角身高的倍数」配的，见 src/data/home.js 的 toySizeRatio：
  吊床 0.95 / 小风车 0.75 / 蹦床 0.55 / 地毯 0.48 /
  小水池 0.44 / 小灯笼 0.44 / 沙坑 0.42 / 藤球 0.37 / 小挂饰 0.35
换素材后想调大小，改这张表就行（不用改图）。

注意：**横宽比特别大的玩具（比如吊床约 1.55:1）不要调得太大**，
      否则在画面边缘会被切掉。尺寸上限有自检保护。


========================================================
六、图标（2 张，可选）
========================================================
文件名：图标-512 / 图标-192
格式：PNG，正方形，不需要透明
说明：只有做「添加到主屏幕」才需要。

========================================================
换素材 / 加素材：各要改什么
========================================================
分三种情况，工作量差很多：

--------------------------------------------------------
【一】换成别的角色 / 别的图（最省事）
--------------------------------------------------------
**只替换图片文件就行，不用改任何东西。**

比如把「主角-待机.png」换成另一个角色的图，
或者把「场景-北京.png」换成别的风景 —— 文件名不变，游戏直接用新的。

--------------------------------------------------------
【二】新增同伴（加一个新角色，比如 3 个变 5 个）
--------------------------------------------------------
**两步，不用改 JS 代码：**

  1. 把图片放进本文件夹，命名成「配角-<名字>」
     例：配角-新角色.png

  2. 在 nahida-travel/assets/manifest.js 的 companions 里加一行：
     newchar: '配角-新角色',

就完了。游戏启动时会**自动把这个角色收录进角色表**：

  · 名字 = 去掉「配角-」前缀的文件名（即「新角色」）
  · 台词、性格等用一套通用的客人台词
  · 旅行途中会遇到 TA，TA 也会来家里串门
  · 出现概率和其他同伴相同

名字想改成别的（不用文件名），或者想给 TA 写专属台词，
就去 src/data/companions.js 里照着已有的格式加一条，
再把清单里那一行的 key 对上就行。

--------------------------------------------------------
【三】新增地点（加一个新地区，比如 17 个变 20 个）
--------------------------------------------------------
**三步：**

  1. 图片放进本文件夹，命名成「场景-<地名>」
     例：场景-蒙德.png

  2. 在 assets/manifest.js 的 backgrounds 里加一行：
     mondstadt: '场景-蒙德',

  3. 在 src/data/destinations.js 的地区表里加一条。
     **注意：地区必须写坐标（lat / lng），否则算不出距离。**
     可以直接写在条目里，不用另外去改坐标表：

       {
         id: 'mondstadt', name: '蒙德', fullName: '蒙德城',
         lat: 31.2, lng: 121.5,        // ← 经纬度，必填
         remoteness: 1.0,              // 偏远系数，越大走得越慢
         bearing: 'e',                 // 方位：n/s/e/w/c
         desc: '……',
         tags: ['city', 'plain'],      // 影响会遇到什么事件
         rarity: 'N', weight: 6,       // 稀有度与抽中权重
         weatherCompat: ['clear', 'cloudy'],
         anchorY: 0.72, depthScale: 1, stampHue: 200,
         palette: { sky: ['#...', '#...'], far: '#...', mid: '#...',
                    near: '#...', ground: '#...' },
         arriveLines: ['……'],
         scenery: [{ name: '…', desc: '…', sticker: 'leaf' }],
         food:    [{ name: '…', desc: '…', sticker: 'candy' }],
         play:    [{ name: '…', desc: '…', sticker: 'map' }]
       }

     scenery / food / play 是用来生成事件和明信片的 —— **每种至少写 1 条**。

【怎么知道自己写对了】
打开游戏 → 右上角齿轮 → 如果素材和数据表对不上，
那里会冒出一栏「素材体检」，直接告诉你：
   · 哪些配角被自动收录了
   · 哪些地区有图但没定义（不会出现在目的地里）
   · 哪些东西还没配图
   · 哪些地区缺坐标
对得上的话，这一栏不会出现。


========================================================
怎么确认生效了
========================================================
打开游戏 → 右上角齿轮（设置）→「图片素材」那栏
会显示「已加载 40 / 40」和已生效的文件名。
数字对得上就说明全部生效了。

没做的条目会自动回退到代码画的占位图，**游戏不会被弄坏**。


========================================================
这个文件夹放在哪
========================================================
默认（也是推荐的）摆法 —— 就在项目里、和入口文件同层：

    nahida-travel/
    ├── 开始游戏.html
    ├── 说明.txt
    ├── 图片素材/          ← 本文件夹
    │   └── （这些图）
    ├── src/
    ├── tools/
    └── docs/

游戏会按「同层 → 上一层 → 上两层」依次找这个文件夹，
**第一个能加载成功的位置就定下来**，后面所有素材都用它。
所以整个 nahida-travel 文件夹拷到哪、改名成什么，都不会失效。

想改这个文件夹的名字也行：改
nahida-travel/assets/manifest.js 里的 dir 字段。


========================================================
关于字体（开源相关）
========================================================
游戏**不打包任何字体文件**，全部使用系统自带字体：

  界面     系统默认无衬线（Windows 用微软雅黑，macOS 用苹方，Linux 用思源/文泉驿）
  明信片手写字   系统自带的楷体/手写体

这样做的好处是**零字体授权风险**（开源项目不用担心字体再分发）。
代价是明信片的"手写感"依赖系统装了楷体：
Windows 和 macOS 都有，部分 Linux 没有，会退化成普通字体。

如果你希望所有平台看起来都一样，可以放一个开源字体进来：
推荐 **霞鹜文楷 LXGW WenKai（SIL OFL 1.1 授权，可自由再分发）**，
放到 nahida-travel/assets/font/ 里，再把 开始游戏.html 里那段
@font-face 的注释取消即可。字体文件较大（完整版 10MB+），
也可以只做子集化。
